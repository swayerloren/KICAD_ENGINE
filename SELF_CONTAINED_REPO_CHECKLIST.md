# Self-Contained Repo Checklist

- repo can be downloaded as a ZIP
- repo opens in VS Code
- one starter prompt exists at `ONE_PROMPT_START.md`
- AI agent startup docs exist at the repo root
- repo health check exists and is safe without KiCad
- KiCad local-install requirement is documented
- no local-only folders are required for first use
- no hidden third-party cloned repos are required for first use
- optional dependencies are documented clearly
- ignored folders are documented clearly
- sample and active project status is documented
- fabrication readiness still requires final checks and human review
