# Datasheet Redistribution Policy

Status: `ACTIVE_POLICY`

## Default Rule

Store source links, metadata, and summaries. Do not bundle datasheet PDFs or vendor documents unless redistribution rights are confirmed.

## Link-Only Preferred

For public GitHub releases, prefer link-only records for:

- Datasheets.
- Reference manuals.
- Application notes.
- Evaluation-board schematics.
- Package drawings.
- Vendor reference designs.

## Human Review Required

Human review is required before committing any vendor document, PDF, schematic, CAD archive, STEP model, or copied reference design.
