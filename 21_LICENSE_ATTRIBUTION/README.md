# License Attribution

## PURPOSE

Track license, attribution, and redistribution review work.

## WHAT_BELONGS_HERE

- Third-party attribution notes.
- License review checklists.
- Datasheet redistribution review summaries.
- Public repo risk notes.

## License And Attribution Files

- `LICENSE_AUDIT.md`
- `THIRD_PARTY_ATTRIBUTION.md`
- `DATASHEET_REDISTRIBUTION_POLICY.md`
- `PUBLIC_REPO_RISK_REGISTER.md`
- `VENDOR_DOCUMENT_POLICY.md`

## WHAT_DOES_NOT_BELONG_HERE

- Legal conclusions presented as legal advice.
- Secrets or private vendor credentials.
- Copyrighted PDFs with unclear redistribution.
- Copied third-party code without license review.

## AI_AGENT_RULES

- Mark uncertain licensing as `requires human review`.
- Prefer link-only records when redistribution is unclear.
- Do not delete risky files automatically.

## SAFE_EDIT_RULES

- Add audit notes and attribution records.
- Preserve prior audits.
- Do not remove files unless explicitly requested.

## PUBLIC_RELEASE_NOTES

Public release needs reviewed license, attribution, datasheet redistribution, and third-party tool records.

Uncertain license or redistribution status must be marked `requires human review`.
