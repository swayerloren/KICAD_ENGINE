# License Audit

Status: `REQUIRES_HUMAN_REVIEW`

## Purpose

Track license readiness before public release.

## Areas To Review

- Root repository license.
- Third-party scripts or copied code.
- Installer dependencies.
- GitHub Actions actions.
- KiCad references.
- Datasheet/source documents.
- Icons/assets.
- Sample projects.

## Rule

Do not treat this file as legal advice. Mark uncertain items `requires human review`.

## Current Release Gate

Public release requires a fresh license audit before publishing.
