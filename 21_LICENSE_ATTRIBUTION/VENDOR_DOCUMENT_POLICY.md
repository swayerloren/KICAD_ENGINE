# Vendor Document Policy

Status: `ACTIVE_POLICY`

## Default

Vendor documents should be referenced by URL and summarized. Do not redistribute files unless rights are confirmed.

## Applies To

- Datasheets.
- Errata.
- App notes.
- Reference manuals.
- Package drawings.
- Board schematics.
- CAD models.
- Reference designs.

## Required Metadata

- Vendor.
- Document title.
- Source URL.
- Revision/date if known.
- Redistribution status.
- Local copy status.
- Notes and limitations.
