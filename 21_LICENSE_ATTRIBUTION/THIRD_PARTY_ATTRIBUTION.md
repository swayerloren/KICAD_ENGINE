# Third Party Attribution

Status: `PLACEHOLDER_REQUIRES_REVIEW`

## Purpose

Track third-party tools, packages, actions, assets, and references that may require attribution.

## Required Fields

- Name.
- Source URL.
- Version or commit when known.
- License.
- How it is used.
- Redistribution status.
- Attribution requirement.
- Public release status.

## Rule

Do not copy third-party code or assets into the repo without license review.
