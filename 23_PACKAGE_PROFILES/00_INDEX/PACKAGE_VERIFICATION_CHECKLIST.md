# Package Verification Checklist

Status: `ACTIVE_CHECKLIST`

Use this checklist before approving a footprint candidate.

## Source

- Exact part number or generic placeholder identified.
- Exact package code identified.
- Package drawing source recorded.
- Manufacturer land pattern source recorded if available.
- Source URL and revision/date recorded.

## Geometry

- Pin/pad count checked.
- Pin/pad numbering checked.
- Pitch checked.
- Pad dimensions checked.
- Drill sizes checked for through-hole parts.
- Exposed pad checked.
- Body outline checked.
- Courtyard clearance checked.
- Fab outline checked.
- Silkscreen does not conflict with pads.
- Pin 1/orientation marker checked.

## KiCad

- Symbol-to-footprint mapping status recorded.
- Footprint library path recorded.
- 3D model path status recorded.
- Project-local copy decision recorded.

## Human Review

Human review is required for connectors, modules, RF, USB-C, BGA, fine-pitch packages, exposed pads, and any package with mechanical fit risk.
