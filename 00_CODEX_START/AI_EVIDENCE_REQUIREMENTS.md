# AI Evidence Requirements

Major KiCad engineering claims require evidence.

## Acceptable Evidence

- Local file inspection.
- Command output.
- KiCad source-file evidence.
- `kicad-cli` ERC/DRC output.
- Datasheet, reference manual, package drawing, or connector drawing.
- User-provided facts.
- Existing repo rules or memory, when clearly cited as memory and not independent proof.

## Claim/Evidence Matrix Required

Create a claim/evidence matrix for major engineering claims, including:

- claim,
- evidence source,
- claim status,
- confidence,
- risk,
- human review required,
- unresolved issue link.

## Unsupported Claim Rule

If evidence is missing, write:

`Unknown - requires source verification`

Do not fill missing values from memory.
