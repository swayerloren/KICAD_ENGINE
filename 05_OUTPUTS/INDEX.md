# 05_OUTPUTS Index

## PURPOSE
AI-readable routing index for generated outputs.

## WHAT_BELONGS_HERE
- Health checks.
- Setup reports.
- Project validation reports.
- Release readiness scorecards.
- NOT_FINAL review/export packages.

## WHAT_DOES_NOT_BELONG_HERE
- Secrets.
- Canonical source files.
- Unreviewed files labeled final.

## AI_AGENT_RULES
- Generated files here do not prove fabrication readiness.
- Link important outputs from `02_HISTORY/`.

## SAFE_EDIT_RULES
- Do not delete prior outputs.
- Do not label fab outputs final without evidence and human review.

## PUBLIC_RELEASE_NOTES
- Clean payload builds should exclude most generated outputs.
