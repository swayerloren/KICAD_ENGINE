# Future Electronics Connector

Status: `SAFE_CONNECTOR_SCAFFOLD`

## Purpose

This connector documents how KiCad Engine may ingest Future Electronics metadata without blind scraping, credentials in repo files, or unsupported sourcing claims. It is an ingestion path for source links and normalized metadata, not an approval path for purchase, lifecycle, package, or footprint decisions.

## Preferred Access Method

Official API/data-feed if authorized, user-provided CSV exports, or manually curated public source links.

Live access is not enabled by documentation alone. Any future live connector must require explicit `--live` or equivalent user approval, read credentials only from environment variables or ignored local config, and fail safely when credentials or terms are missing.

## Allowed Inputs

- Official API responses when the user has authorized access and terms allow the use.
- User-provided CSV exports that have been sanitized of secrets and private account data.
- Manual source-link records with source URL and retrieval date.
- Public metadata fields needed for component research, source linking, and gap reporting.

## Prohibited Inputs

- API keys, tokens, cookies, session IDs, private quotes, order history, account numbers, or credentials.
- Bulk scraped pages or data collected by bypassing login, CAPTCHA, robots controls, rate limits, or site terms.
- Downloaded datasheet PDFs by default.
- Supplier package text promoted directly to verified KiCad footprint status.

## Normalized Output Fields

At minimum, normalized records should include:

| Field | Required | Default If Unknown |
| --- | --- | --- |
| `supplier` | Yes | `Future Electronics` |
| `manufacturer` | Yes | `Unknown - requires source verification` |
| `manufacturer_part_number` | Yes | `Unknown - requires source verification` |
| `supplier_sku` | Optional | blank |
| `product_url` | Desired | `TODO_SOURCE_REQUIRED` |
| `datasheet_url` | Desired | `TODO_SOURCE_REQUIRED` |
| `package` | Desired | `Unknown - requires source verification` |
| `lifecycle_status` | Optional | `UNVERIFIED` |
| `stock_status` | Optional | `UNVERIFIED_SNAPSHOT` |
| `retrieved_at` | Yes | ISO timestamp generated by the importer |
| `verification_status` | Yes | `UNVERIFIED` |
| `human_review_required` | Yes | `true` for exact sourcing or high-risk parts |

## AI Agent Rules

- Treat Future Electronics data as source metadata until verified against official manufacturer documentation or human review.
- Do not infer exact voltage, current, package drawing, pinout, footprint, or lifecycle from listing text alone.
- Route package and footprint uncertainty to `29_FOOTPRINT_GAP_ANALYSIS` and `30_SUPPLIER_FOOTPRINT_MATCHES`.
- Keep generated records `UNVERIFIED` unless a separate verification record names the evidence.

## Review Gate

A Future Electronics record may support candidate selection or gap reporting. It does not approve a BOM line, substitute, footprint, assembly package, or procurement decision without current source review and human approval where required.
