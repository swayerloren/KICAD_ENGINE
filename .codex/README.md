# .codex

## PURPOSE
Workspace-local Codex configuration and prompt support.

## WHAT_BELONGS_HERE
- Codex workspace configuration.
- Codex prompt files that are specific to this repo.

## WHAT_DOES_NOT_BELONG_HERE
- Secrets, tokens, API keys, passwords, or personal credentials.
- KiCad project source files or generated manufacturing outputs.

## AI_AGENT_RULES
- Read root `AGENTS.md` before using this folder.
- Back up configuration before changing MCP or tool settings.

## SAFE_EDIT_RULES
- Edit only when the user explicitly asks for Codex configuration or prompts.
- Do not change global Codex configuration from this folder.

## PUBLIC_RELEASE_NOTES
- Public payloads must exclude machine-local credentials and private configuration.
