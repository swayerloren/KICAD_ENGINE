# Case Studies

Status: `PATTERN_EXTRACTION_ONLY`

This folder stores normalized lessons from good-board and bad-board examples.

## Core Rule

Case studies are not source-of-truth design approval. They are pattern-extraction
inputs.

Use them to:

- feed style scorecards,
- feed false-pass prevention,
- feed quality-gate examples,
- explain why an existing rule matters.

Do not use them to:

- bypass datasheet evidence,
- approve footprints or orientations,
- claim EMI, USB, or power integrity success by analogy alone.
