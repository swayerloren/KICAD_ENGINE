# Symbol Library Rules

Status: `NORMALIZED_REFERENCE`

## Rules

- organize symbols by function, not just manufacturer
- prefer exact pinout evidence over existing-library similarity
- use English and stable naming conventions for portable library data
- keep symbol naming filesystem-safe and predictable
- treat KLC as guidance, not as proof of a symbol's correctness

## Repo Interpretation

- symbol selection still requires exact datasheet verification
- scraped KLC pages are not approval by themselves
- active project gates remain stricter than generic library guidance
