# Footprint Library Rules

Status: `NORMALIZED_REFERENCE`

## Rules

- footprint naming and organization should follow KiCad library conventions
- package drawing evidence beats any generic convention
- do not verify a footprint from name similarity alone
- use local project copies when a footprint must diverge from the stock library
- connector footprints still require mechanical orientation proof

## Repo Interpretation

- official KLC guidance is helpful for contribution hygiene
- package drawing, pin mapping, and orientation proof remain the real gate
- 3D-model presence can support review but does not replace drawing checks
