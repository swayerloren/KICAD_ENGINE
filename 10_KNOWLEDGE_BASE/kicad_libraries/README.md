# KiCad Libraries Knowledge

Status: `NORMALIZED_REFERENCE`

This folder summarizes the KiCad library conventions and repo-safe usage rules
for symbols, footprints, 3D models, and library structure.

## Canonical Files

- `SYMBOL_LIBRARY_RULES.md`
- `FOOTPRINT_LIBRARY_RULES.md`
- `KICAD_LIBRARY_CONVENTIONS_SUMMARY.md`

## Core Rule

The KiCad Library Convention is guidance for official-library contribution. It
does not override exact manufacturer package drawings, connector orientation
truth, or project-specific verification gates.
