# KiCad Library Conventions Summary

Status: `NORMALIZED_REFERENCE`

## What KLC Is

The KiCad Library Convention describes how the official KiCad libraries prefer
to organize and review symbols, footprints, models, and related assets.

## What KLC Is Not

- not a replacement for manufacturer package drawings
- not a connector-orientation proof system
- not a blanket approval for project-local footprints
- not stronger than the repo's footprint/package gate

## Repo Use

Use KLC to improve consistency and contribution hygiene. Use exact part/package
evidence to approve engineering decisions.
