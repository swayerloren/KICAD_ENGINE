# Source Citation Rules

## When Sources Are Required

Sources are required for:

- Exact electrical values.
- Pinouts.
- Package dimensions.
- Footprint approval.
- Connector orientation.
- Boot straps.
- Regulator capacitor requirements.
- RF keepouts.
- USB, CAN, LIN, RS485, and automotive requirements.
- BOM MPN claims.

## Acceptable Source Types

- Vendor datasheet.
- Vendor reference manual.
- Vendor application note.
- Vendor hardware design guide.
- Exact connector or package drawing.
- Trusted board-house requirement page.
- User-confirmed written requirement.

## Citation Content

Record:

- Source title.
- Vendor or publisher.
- URL or local path.
- Revision/date if available.
- Relevant section, page, or table when available.
- Verification status.

## Rule

If a citation is missing, the claim stays unverified.
