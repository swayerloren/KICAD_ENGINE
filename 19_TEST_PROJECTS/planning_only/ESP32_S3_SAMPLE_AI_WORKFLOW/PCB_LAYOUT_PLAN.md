# PCB Layout Plan

Status: `EXAMPLE_ONLY_PLANNING_ONLY`

## Layout Concerns

- Place module for antenna keepout and board-edge requirements.
- Keep power regulator layout source-backed.
- Route USB as controlled high-speed interface when used.
- Keep ESD protection close to connector when used.
- Review connector orientation and mechanical fit.

## Review Gates

- Footprint package drawing review.
- Connector orientation human review.
- RF/antenna keepout review.
- DRC required if a PCB is created in a future disposable project.
