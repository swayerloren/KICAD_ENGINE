# Component Selection

Status: `EXAMPLE_ONLY_PLANNING_ONLY`

## Candidate Blocks

- ESP32-S3 module: exact part number required.
- 3.3 V regulator: exact part required.
- USB connector: exact manufacturer part required.
- ESD protection: exact part required.
- Reset/boot controls: exact switch/button choices required.
- Status LED: exact LED/resistor values require requirements and source review.

## Rules

- Do not choose parts from memory.
- Do not approve generic USB-C connectors.
- Do not approve module footprints without exact module datasheet and land pattern.
- Mark all candidates `UNVERIFIED_PLACEHOLDER` until sourced.
