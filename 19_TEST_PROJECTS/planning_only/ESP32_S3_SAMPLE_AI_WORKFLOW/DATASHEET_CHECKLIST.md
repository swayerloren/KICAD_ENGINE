# Datasheet Checklist

Status: `EXAMPLE_ONLY_PLANNING_ONLY`

## Required Sources

- ESP32-S3 module datasheet for exact variant.
- Espressif hardware design guidelines.
- Regulator datasheet.
- USB connector drawing.
- ESD protection datasheet.
- Any oscillator, antenna, or RF connector sources if used.

## Required Checks

- Power supply limits.
- Boot/strapping pins.
- EN/reset requirements.
- USB/JTAG/UART programming constraints.
- Module pad land pattern.
- Antenna keepout or external antenna connector.
- Recommended decoupling and layout notes.

## Rule

Do not fill exact values unless a source is cited.
