# Functional Block Spacing Rules

1. Functional blocks must have visible separation.
2. Support passives should sit near the symbol they support.
3. Symbols must not visually crowd until text and pins become hard to inspect.
4. Dense regions require expansion before the schematic may pass readability.
5. USB-C, buck, and ESP32 support parts should form readable subclusters instead of being scattered across the sheet.
6. Mounting and mechanical notes should be visually separate from active circuitry.
