# Reference / Value Text Placement Rules

## `TEXT_OWNERSHIP_REQUIRED`

1. Reference and value text must not overlap wires, pins, labels, symbol
   bodies, or other text.
2. Every visible reference and value must visibly belong to its own symbol.
3. No value or reference may float in blank space or sit closer to a different
   part than its own symbol.
4. Wires must not run through references, values, or labels when a readable
   alternative exists.
5. Long review detail belongs in hidden fields, reports, or notes regions, not
   in crowded visible values.
6. Estimated text-overlap findings are blockers until cleared or explicitly
   human-reviewed.
