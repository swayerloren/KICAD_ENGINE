# Assembly Notes Required Rules

Status: `ACTIVE_RULES`

Every NOT_FINAL PCBA upload package must include `Assembly_Notes.md`.

## Required Sections

- Project, revision, date, and `NOT_FINAL` status.
- General assembly instructions.
- Substitution policy.
- Barrel jack orientation notes when present.
- USB-C orientation notes when present.
- IC pin 1 notes.
- Diode/LED polarity notes.
- Polarized capacitor notes.
- DNP table.
- Approved substitutions table.
- Project-specific special instructions.

Missing assembly notes block package readiness.
