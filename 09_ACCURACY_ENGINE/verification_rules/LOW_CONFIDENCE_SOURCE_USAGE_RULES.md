# Low Confidence Source Usage Rules

Status: `ACTIVE_EVIDENCE`

## Scope

These rules apply to forums, peer-review threads, video pages, tutorial
collections, university training notes, and case-study summaries.

## Rules

1. Treat these sources as guidance, not proof.
2. Do not approve footprints, routing, orientation, EMC, or fab readiness from
   these sources alone.
3. Promote a lesson into a checklist or blocker only when it is backed by
   official documentation or repeated engineering consensus plus repo evidence.
4. If a claim depends mainly on low-confidence material, mark it
   `UNVERIFIED` or `NEEDS_HUMAN_REVIEW`.
5. Raw captures from these sources belong in history or license quarantine, not
   source-of-truth engineering folders.
