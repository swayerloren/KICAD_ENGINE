# JLCPCB Pre-Upload Checklist

Status: `ACTIVE_CHECKLIST`

- [ ] Phase gate allows NOT_FINAL export.
- [ ] ERC evidence exists.
- [ ] DRC with schematic parity passes.
- [ ] No unrouted nets remain or LJ-approved exceptions are documented.
- [ ] Gerbers exported as `NOT_FINAL`.
- [ ] Drill files exported.
- [ ] Gerbers reviewed in an external viewer.
- [ ] `BOM_JLCPCB.csv` uses required JLCPCB columns.
- [ ] `CPL_JLCPCB.csv` uses required JLCPCB columns.
- [ ] JLCPCB BOM validator run.
- [ ] JLCPCB CPL validator run.
- [ ] `gerbers.zip` exists in the JLCPCB folder.
- [ ] `Assembly_Notes.md` exists.
- [ ] `orientation_checks.md` exists in review folder.
- [ ] Barrel jack orientation verified.
- [ ] USB-C orientation verified.
- [ ] All connector orientations verified.
- [ ] Pin 1 verified.
- [ ] Diode/LED polarity verified.
- [ ] Capacitor polarity verified.
- [ ] Solder paste layers included.
- [ ] Board outline included.
- [ ] Mounting holes/slots included.
- [ ] Output marked `NOT_FINAL`.
- [ ] LJ approved upload.
