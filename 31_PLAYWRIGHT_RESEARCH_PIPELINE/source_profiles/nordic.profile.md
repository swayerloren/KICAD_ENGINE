# Nordic Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official Nordic nRF documentation, product pages, dev kit pages, antenna/RF notes, and package/source links.

## Preferred Access Method

Official Nordic docs and product pages.

## Login/API Key Required

Public docs generally do not require keys. Stop if login/terms appear.

## Playwright Allowed

Public-page source-link capture only.

## Fields May Be Captured

- product URL
- datasheet/specification URL
- reference design/dev kit links
- package text
- RF/layout document links

## Must Not Be Captured

- account pages
- private downloads
- copied PDFs by default

## Rate Limit Guidance

Low volume.

## Redistribution Guidance

Link-only unless reviewed.

## Notes For Codex/Claude

RF layout and antenna claims require official document review and human layout review.
