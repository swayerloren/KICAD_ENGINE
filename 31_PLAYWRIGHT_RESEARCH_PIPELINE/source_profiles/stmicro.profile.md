# STMicro Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official STM32 product pages, datasheets, reference manuals, errata, app notes, Nucleo/Discovery/Eval board pages, and ST-Link documentation.

## Preferred Access Method

Official ST product/documentation pages.

## Login/API Key Required

No API key expected for public document links. Some downloads or tools may have access terms; do not bypass them.

## Playwright Allowed

Allowed for public source-link capture and screenshots only.

## Fields May Be Captured

- official part/family URL
- document title/type
- document source URL
- package/order-code text
- board reference links

## Must Not Be Captured

- PDF bundles by default
- account/session data
- exact claims without datasheet section review

## Rate Limit Guidance

Low volume; prefer official search/product pages.

## Redistribution Guidance

Link-only unless redistribution permission is confirmed.

## Notes For Codex/Claude

ST package/order-code mapping must still be verified before footprint approval.
