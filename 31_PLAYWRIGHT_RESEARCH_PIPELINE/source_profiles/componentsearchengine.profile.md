# ComponentSearchEngine Source Profile

Source confidence level: `PUBLIC_LIBRARY_VENDOR`

## Source Purpose

EDA model discovery, CAD availability, and part-source links.

## Preferred Access Method

Public page link capture and manual review.

## Login/API Key Required

Downloads may require terms/account. Do not automate protected access.

## Playwright Allowed

Public page evidence only.

## Fields May Be Captured

- public page URL
- part number
- library availability notes
- package text
- datasheet/source links if public

## Must Not Be Captured

- account data
- downloaded libraries without license review
- scraped page archives

## Rate Limit Guidance

Small batches only.

## Redistribution Guidance

Link-only unless license permits redistribution.

## Notes For Codex/Claude

Treat as candidate evidence, not footprint approval.
