# Espressif Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official ESP32/ESP8266 datasheets, module docs, design guides, errata, hardware reference designs, and product pages.

## Preferred Access Method

Official Espressif documentation pages and official GitHub/reference design links.

## Login/API Key Required

No API key expected for public documentation pages.

## Playwright Allowed

Allowed for public documentation/product page source-link capture and screenshots.

## Fields May Be Captured

- official product page URL
- datasheet/source document URL
- document title/type
- module/package notes
- reference design links

## Must Not Be Captured

- bulk downloaded PDFs by default
- copied repository files without license review
- claims of exact specs without document review

## Rate Limit Guidance

Low volume and source-link-first.

## Redistribution Guidance

Prefer link-only records unless redistribution rights are confirmed.

## Notes For Codex/Claude

Official source links are high-confidence, but exact values still require datasheet section review.
