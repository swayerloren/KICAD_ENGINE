# LCSC Source Profile

Source confidence level: `DISTRIBUTOR_OFFICIAL`

## Source Purpose

LCSC part number, MPN, public stock/pricing summary, package text, datasheet links, and assembly-risk metadata.

## Preferred Access Method

Official/approved API or data feed first. User-provided CSV export second. Manual source-link records third.

## Login/API Key Required

May require approved access for robust live data. Do not automate logged-in pages.

## Playwright Allowed

Allowed only for public-page source evidence when terms allow. Stop on block, CAPTCHA, or login.

## Fields May Be Captured

- public product URL
- LCSC part number
- manufacturer and MPN
- public stock/price summary
- package text
- datasheet link

## Must Not Be Captured

- private account data
- cookies/session data
- automated catalog scraping
- downloaded PDFs by default

## Rate Limit Guidance

Prefer user exports. Keep live page checks rare and slow.

## Redistribution Guidance

Link-only metadata. No bundled supplier pages or PDFs.

## Notes For Codex/Claude

Treat all LCSC package and stock data as time-sensitive and unverified until reviewed.
