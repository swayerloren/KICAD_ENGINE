# Microchip Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official PIC, dsPIC, AVR, Curiosity/Explorer board, PICKIT, ICSP, datasheet, errata, and app-note links.

## Preferred Access Method

Official Microchip product and documentation pages.

## Login/API Key Required

Public docs usually do not require API keys. Stop if login or terms gate appears.

## Playwright Allowed

Allowed for public source-link evidence only.

## Fields May Be Captured

- product page URL
- document links
- package text
- development board links
- programming/debug document links

## Must Not Be Captured

- restricted downloads
- account pages
- copied PDFs by default

## Rate Limit Guidance

Small batches only.

## Redistribution Guidance

Link-only unless redistribution is confirmed.

## Notes For Codex/Claude

Exact oscillator, MCLR, ICSP, USB, and package decisions require datasheet/app-note review.
