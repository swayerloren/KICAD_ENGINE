# SnapEDA Source Profile

Source confidence level: `PUBLIC_LIBRARY_VENDOR`

## Source Purpose

Public symbol, footprint, 3D model, and EDA-library candidate discovery.

## Preferred Access Method

Public library page links and manual download/review workflows. Do not bulk download.

## Login/API Key Required

Some downloads or metadata may require account access. Do not automate logged-in access.

## Playwright Allowed

Allowed for public-page source evidence and screenshots only.

## Fields May Be Captured

- public library page URL
- part number
- advertised symbol/footprint availability
- package name text
- source confidence notes

## Must Not Be Captured

- logged-in downloads
- proprietary library files
- account data
- copied EDA assets without license review

## Rate Limit Guidance

Manual-sized public-page checks only.

## Redistribution Guidance

Link-only unless license allows redistribution.

## Notes For Codex/Claude

Third-party EDA assets are candidates only and require package drawing review before KiCad use.
