# Texas Instruments Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official TI product pages, datasheet links, package drawing links, app notes, EVM references, and lifecycle/package metadata.

## Preferred Access Method

Official TI product and documentation pages.

## Login/API Key Required

Public documents usually do not require API keys. Stop if login/terms gate appears.

## Playwright Allowed

Allowed for public source-link capture and screenshots.

## Fields May Be Captured

- product URL
- datasheet URL
- package drawing URL
- package text
- lifecycle/status text
- EVM/reference links

## Must Not Be Captured

- logged-in data
- private ordering data
- downloaded PDFs by default

## Rate Limit Guidance

Low volume and source-link-first.

## Redistribution Guidance

Link-only unless rights are confirmed.

## Notes For Codex/Claude

Package drawing links are evidence sources, but footprint verification still needs detailed review.
