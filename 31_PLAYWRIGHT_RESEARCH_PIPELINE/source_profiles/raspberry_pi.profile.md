# Raspberry Pi Source Profile

Source confidence level: `OFFICIAL_MANUFACTURER`

## Source Purpose

Official RP2040/RP2350 datasheets, hardware design guides, Pico board documentation, and source links.

## Preferred Access Method

Official Raspberry Pi documentation pages and public GitHub links.

## Login/API Key Required

No API key expected for public docs.

## Playwright Allowed

Allowed for public documentation link capture and screenshots.

## Fields May Be Captured

- product/documentation URL
- datasheet/source links
- hardware design guide links
- board/document links

## Must Not Be Captured

- copied PDFs by default
- source files without license review
- claims of exact specs without document review

## Rate Limit Guidance

Low volume.

## Redistribution Guidance

Link-only unless license permits redistribution.

## Notes For Codex/Claude

Official docs are high-confidence but not a substitute for exact review.
