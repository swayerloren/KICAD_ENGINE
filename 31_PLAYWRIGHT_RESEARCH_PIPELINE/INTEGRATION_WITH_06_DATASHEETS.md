# Integration With 06_DATASHEETS

Playwright research may propose datasheet/source-link records for `06_DATASHEETS`, but default mode must be dry-run.

## Allowed Outputs

- Source URL records.
- Document titles.
- Document type labels.
- Proposed target folders.
- Retrieval timestamps.
- Redistribution status notes.

## Not Allowed By Default

- PDF downloads.
- Bundled copyrighted documents.
- Claims that a datasheet was reviewed unless a human or separate extraction workflow reviewed it.

## Promotion Rule

A captured datasheet link may be added to `06_DATASHEETS` only after source profile rules and redistribution policy are reviewed. Store link-only records unless redistribution permission is confirmed.
