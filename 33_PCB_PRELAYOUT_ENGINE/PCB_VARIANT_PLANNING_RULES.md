# PCB Variant Planning Rules

## Hard Rules

1. Real PCB placement or routing may not begin until at least three variants exist.
2. Variants must be generated by the prelayout engine, not just described loosely in prose.
3. Every variant must record:
   - board profile
   - fixed mechanical references
   - connector truth results
   - RF keepout treatment
   - projected route set
   - projected open-net count
   - risk notes
4. At least one variant must reach `PASS` before real PCB placement or routing may begin.
5. A selected variant is not enough by itself if the selected variant still carries projected open nets or connector-direction failure.

## Variant Minimum Content

- one stable `variant_id`
- one stable `strategy_id`
- connector placements with intended edge and mating direction
- grouped component placements for power, RF, USB/data, and test access
- a projected route set using the trace-projection rules
- a score payload using the variant-score schema

## Variant Failure Examples

- USB-C faces into the board
- barrel jack front does not face off-board
- RF keepout is crowded or crossed
- mounting holes steal the connector service envelope
- route projections still leave required nets open
- only one or two variants were produced
