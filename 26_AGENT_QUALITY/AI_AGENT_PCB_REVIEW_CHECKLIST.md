# AI Agent PCB Review Checklist

Status: `ACTIVE_CHECKLIST`

Use this checklist before claiming a schematic or PCB review is complete.

- Did the claim rely on live KiCad evidence before summaries?
- Did any low-confidence source get treated as proof instead of guidance?
- Are connector opening direction, pin side, and board-edge direction proven
  separately?
- Are open nets and schematic parity checked explicitly?
- Are routing geometry and detour quality checked explicitly?
- Is RF keepout handled as a hard gate?
- Is USB routing judged on compactness and pair sanity, not just connection?
- Is footprint approval backed by package evidence?
- If any answer is no, the review result is not final.
