# Agent Quality

Status: `MANDATORY_CLOSEOUT_QUALITY_LAYER`

## PURPOSE

Store AI quality-gate summaries, scoring policy extensions, templates, and meta-evaluation docs. This folder mirrors the mandatory `00_CODEX_START/AI_*` rules and gives agents a concise subsystem entry point for truthfulness, uncertainty, and claim-evidence discipline.

## WHAT_BELONGS_HERE

- Agent scoring policy summaries.
- Quality-gate review plans.
- Prompt quality checks.
- Links to generated AI-quality records.
- Failure-pattern summaries that help stop repeated KiCad AI mistakes.

## WHAT_DOES_NOT_BELONG_HERE

- Raw command logs.
- Project-specific engineering decisions.
- Secrets or AI credentials.
- Fabrication approval.
- Forum, video, or case-study anecdotes promoted as source-of-truth evidence.

## AI_AGENT_RULES

- Use `00_CODEX_START/AI_*` as the mandatory startup policy.
- Use `02_HISTORY/ai_*` folders for records.
- Do not inflate scores.
- Mark uncertainty explicitly.
- If engineering claims are made, create a self-review, scorecard, claim/evidence matrix, and uncertainty log before final response.
- If any claim was inferred, guessed, weakly sourced, or generated by dry-run tooling, create a hallucination-risk log.
- If any high-risk decision remains unresolved, mark the response `BLOCKED_UNTIL_HUMAN_REVIEW`.

## Required Closeout Record Matrix

| Work Type | Self-Review | Scorecard | Claim/Evidence Matrix | Uncertainty Log | Hallucination-Risk Log |
| --- | --- | --- | --- | --- | --- |
| Documentation-only with no engineering claims | Recommended | Recommended | Optional | Optional | Optional |
| Repo workflow or safety changes | Required | Required | Required for major claims | Required for unverified scope | Required if inferred |
| Datasheet/component/source work | Required | Required | Required | Required | Required for source-link-only data |
| KiCad schematic/PCB/fab work | Required | Required | Required | Required | Required for any unresolved risk |
| Supplier/Playwright research | Required | Required | Required | Required | Required unless all data is official and verified |

## Scoring Floor Rules

- Do not score above 80 if validation was not run.
- Do not score above 70 if important claims are source-link-only.
- Do not score above 60 if a high-risk footprint, connector, PMOS, ESD, regulator, RF, USB, CAN, or fabrication decision remains unresolved.
- Mark `BLOCKED_UNTIL_HUMAN_REVIEW` for unverified connector orientation, unverified exact footprint, missing required source, required ERC/DRC not run, or unreviewed manufacturing output.

## SAFE_EDIT_RULES

- Add policy summaries and index docs.
- Do not delete prior scorecards or risk logs.

## PUBLIC_RELEASE_NOTES

Public quality docs should make clear that AI review is not certified engineering approval.
