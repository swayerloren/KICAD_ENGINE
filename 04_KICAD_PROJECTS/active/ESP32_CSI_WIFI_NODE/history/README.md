# ESP32_CSI_WIFI_NODE Project History

Project-specific evidence goes here.

## Folder Map

- `sessions/`: session summaries.
- `command_logs/`: commands and important outputs.
- `failed_attempts/`: failed attempts and recovery notes.
- `user_corrections/`: user correction records.
- `design_decisions/`: decision records and rationale.
- `issue_logs/`: open and closed issue records.
- `workflow_runs/`: project workflow evidence.
- `verification_runs/`: ERC, DRC, BOM, footprint, and fab-package checks.

Do not store secrets. Do not store durable project rules here if they belong in `memory/`.
