# 04_KICAD_PROJECTS Index

## PURPOSE
AI-readable routing index for KiCad project folders.

## WHAT_BELONGS_HERE
- `active/`
- `archive/`
- `templates/`

## WHAT_DOES_NOT_BELONG_HERE
- Global scripts or tool repos.
- Datasheet archives.
- Public release binaries.

## AI_AGENT_RULES
- Read `00_CODEX_START/CURRENT_PROJECT.md` before project work.
- Read project memory/history before touching project files.

## SAFE_EDIT_RULES
- Preserve project source files unless explicitly asked to edit.
- Run ERC/DRC or document why checks could not run after relevant edits.

## PUBLIC_RELEASE_NOTES
- Remove or sanitize private projects from public payloads unless intentionally included as safe samples.
