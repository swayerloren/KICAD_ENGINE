# KiCad Engine Vs Cloud PCB AI Tools

Status: `POSITIONING_DRAFT`

## Positioning

KiCad Engine is designed to become stronger for local-first KiCad users who want transparent files, Git history, local prompts, auditable source records, and human review gates.

## Careful Comparison

| Category | KiCad Engine Direction |
| --- | --- |
| Local vs cloud | Local-first workspace using the user's installed KiCad app. |
| EDA environment | KiCad-native support, not a separate PCB editor. |
| Memory | Repo-owned memory/history files. |
| Data | User-owned datasheet and component records. |
| Verification | CLI-verifiable ERC/DRC/report workflows where available. |
| Review | Explicit human review gates. |
| Version control | Git-friendly repo structure. |

## Limits

Do not claim feature parity or superiority over a cloud PCB AI tool without benchmark evidence. Use `15_BENCHMARKS/` before making comparison claims.
