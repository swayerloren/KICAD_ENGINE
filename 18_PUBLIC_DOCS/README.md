## AI_AGENT_RULES

- Keep claims realistic and evidence-backed.
- Do not claim KiCad Engine replaces KiCad.
- Do not claim Flux-level parity without benchmark evidence.

## SAFE_EDIT_RULES

- Add docs and public-facing checklists.
- Preserve existing root and `docs/` files unless explicitly updating them.

## PUBLIC_RELEASE_NOTES

Docs must be beginner-friendly, technically accurate, and clear about AI limits.

Do not make unsupported claims about replacing KiCad or outperforming cloud PCB AI tools.
