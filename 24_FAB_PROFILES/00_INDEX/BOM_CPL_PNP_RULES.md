# BOM CPL PNP Rules

Status: `ACTIVE_RULES`

## BOM Requirements

Review BOM for:

- Reference designator.
- Quantity.
- Manufacturer part number.
- Value.
- Package.
- Description.
- Datasheet/source link.
- DNP status.
- Sourcing status.

## CPL / PNP Requirements

Review pick-and-place data for:

- Reference designator.
- X/Y coordinates.
- Rotation.
- Side.
- Package name.
- Polarity/orientation.
- Connector orientation.
- Components excluded from assembly.

## Rule

Do not assume a fab-house accepts a BOM/CPL format unless the profile is sourced or the user confirms it.
