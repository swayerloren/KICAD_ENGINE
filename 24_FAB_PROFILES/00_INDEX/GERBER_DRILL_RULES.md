# Gerber Drill Rules

Status: `ACTIVE_RULES`

## Default

Gerber and drill outputs generated by AI-assisted workflows must be labeled `NOT_FINAL`.

## Required Review

- Layer set.
- Board outline.
- Copper layers.
- Soldermask layers.
- Silkscreen layers.
- Paste layers when assembly is involved.
- Excellon drill files.
- Plated vs non-plated drill distinction.
- Gerber units and format.
- Drill map/report when available.

## Fab-Specific Rule

Do not invent fab-house Gerber or drill requirements. Link to current official fab documentation and record the source date before marking a profile verified.
