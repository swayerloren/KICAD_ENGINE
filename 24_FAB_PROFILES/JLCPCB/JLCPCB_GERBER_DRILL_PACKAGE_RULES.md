# JLCPCB Gerber And Drill Package Rules

Status: `ACTIVE_RULES`

## Required Package

Use `gerbers.zip` inside the JLCPCB revision folder.

## Expected Contents

- Top and bottom copper.
- Inner copper layers if multi-layer.
- Top and bottom solder mask.
- Top and bottom silkscreen.
- Top and bottom solder paste for assembly.
- Board outline / Edge.Cuts.
- Excellon NC drill file.
- Drill map recommended.

Gerbers must be reviewed in an external Gerber viewer before upload approval.
