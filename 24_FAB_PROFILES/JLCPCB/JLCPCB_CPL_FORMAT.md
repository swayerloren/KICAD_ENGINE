# JLCPCB CPL Format

Status: `ACTIVE_RULES`

## Required Columns

```csv
Designator,Mid X,Mid Y,Layer,Rotation
```

## Rules

- `Mid X` and `Mid Y` must be numeric millimeter coordinates.
- `Layer` must be `Top` or `Bottom`.
- `Rotation` must be numeric degrees.
- Rotation must be visually checked before upload.
- Connector orientation and polarized part orientation must be separately reviewed.
