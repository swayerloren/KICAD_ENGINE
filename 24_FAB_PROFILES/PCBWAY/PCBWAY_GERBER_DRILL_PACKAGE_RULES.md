# PCBWay Gerber And Drill Package Rules

Status: `ACTIVE_RULES`

## Required Package

Use `gerbers.zip` inside the PCBWay revision folder.

## Expected Contents

- Copper / track layers.
- Solder mask layers.
- Silkscreen layers.
- Solder paste layers for assembly.
- Board outline / mechanical / Edge.Cuts layer.
- Excellon drill files.
- Slots and cutouts where applicable.

Gerbers must be reviewed in an external viewer before upload approval.
