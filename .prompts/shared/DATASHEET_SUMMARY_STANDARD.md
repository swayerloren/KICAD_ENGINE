# Datasheet Summary Standard

Use this standard for AI-readable datasheet summaries.

## Required Sections

- Part number and vendor.
- Document title.
- Document type.
- Revision and date if available.
- Source URL.
- Public redistribution status.
- Local filename or link-only status.
- Verification level.
- Electrical overview.
- Pinout notes.
- Package notes.
- Recommended operating conditions.
- Absolute maximum ratings.
- Layout requirements.
- External parts required.
- Errata or warnings.
- KiCad symbol/footprint/3D candidates.
- Unknowns requiring verification.

## Copyright Policy

- Prefer source links and summaries.
- Do not mass-download.
- Do not scrape aggressively.
- Do not bypass vendor restrictions.
- Do not include copyrighted PDFs in a public repo unless redistribution is clearly permitted.

## Accuracy Policy

- Quote minimally.
- Paraphrase technical requirements with source references.
- Use `Unknown - requires source verification` for missing exact values.
- Do not merge facts across similar parts unless the source explicitly covers the selected part.

## KiCad Use

Before using a datasheet summary for schematic or PCB work, verify:

- Symbol pin numbers.
- Footprint pad numbers.
- Package drawing.
- Orientation marks.
- Required passives and protection.
- Layout constraints.
- Thermal and mechanical constraints.
