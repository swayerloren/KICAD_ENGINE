# Supplier CAD Model Rules

## Hard Rules

1. Supplier CAD model is not automatically trusted.
2. CAD-model availability does not prove footprint accuracy.
3. CAD geometry still requires package-drawing and pad-mapping review.
4. Connector and module CAD requires mechanical orientation review.
5. Imported CAD must not override exact manufacturer package evidence.

## Acceptable Use

- candidate geometry preview
- mechanical-envelope sanity checks
- sourcing convenience
- investigation starting point

## Not Acceptable As Final Proof

- footprint pad dimensions
- pad numbering
- connector mouth direction
- antenna keepout
- assembly polarity
