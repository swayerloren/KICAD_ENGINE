# Reporting Security Issues

Status: `PUBLIC_DRAFT`

## What To Report

- Secret leaks.
- Unsafe installer behavior.
- Scripts that silently install or delete files.
- Scripts that write into installed KiCad folders.
- Credential capture.
- Release artifact tampering.

## How To Report

Use the reporting channel described in root `SECURITY.md`. If no private channel exists yet, open a minimal GitHub issue that does not include secrets or exploit details.

## Do Not Include

- Real credentials.
- Private project files.
- Customer data.
- Exploit details that increase user risk.
