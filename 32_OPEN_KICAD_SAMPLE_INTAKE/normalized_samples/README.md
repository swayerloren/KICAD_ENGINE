# Normalized Samples

This directory contains working copies created from `../imported_originals/` for review, normalization, and benchmark preparation.

Normalized samples are still not trusted designs. They must pass:
- License review.
- KiCad file audit.
- ERC/DRC review where applicable.
- Visual review.
- Footprint/package review.
- NOT_FINAL output rules for any generated review artifacts.

Do not treat a normalized sample as fabrication-ready.
