# Sample Candidates

Candidate records for open KiCad projects that may be useful as reference designs, benchmark inputs, or workflow test cases.

Only records belong here. Do not place cloned repositories, downloaded zip files, or KiCad project folders in this directory.

Every candidate must record:
- Source URL.
- Project owner.
- License status.
- Attribution status.
- Whether real KiCad files are present.
- Whether public bundling is allowed, blocked, or requires human review.

Candidate status is not verification. A candidate remains `UNVERIFIED` until license screening, file audit, and technical review are complete.
