# Sample Candidates

Candidate records for open KiCad projects that may be useful as reference
designs, benchmark inputs, or workflow test cases.

Only records belong here. Do not place cloned repositories, downloaded zip
files, or KiCad project folders in this directory.

Every candidate must record:

- source URL
- project owner
- license status
- attribution status
- whether real KiCad files are present
- whether public bundling is allowed, blocked, or requires human review
- why the sample may be useful for schematic or PCB learning

Candidate status is not verification. A candidate remains `UNVERIFIED` until
license screening, file audit, metric extraction, and technical review are
complete.

Use `sample_candidate_template.json` as the starting schema for new records.
