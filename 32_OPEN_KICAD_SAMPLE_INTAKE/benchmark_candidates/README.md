# Benchmark Candidates

This directory tracks sample projects being considered for `15_BENCHMARKS`.

A sample may become a benchmark candidate only after:
- Source and license are recorded.
- Attribution is preserved.
- Public bundling status is known or the benchmark remains link-only.
- Technical review scope is defined.
- The project is not presented as verified simply because it builds or opens.

Do not store final benchmark results here. Benchmark results belong under `15_BENCHMARKS/results/`.
