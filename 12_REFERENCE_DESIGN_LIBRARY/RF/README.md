# RF Reference Designs

Use this folder for RF module, antenna, U.FL/IPEX, SMA, RF matching, feedline, keepout, and wireless module reference design records.

## Preferred Sources

- RF module vendor hardware design guides.
- Antenna vendor layout notes.
- Official evaluation board RF sections.
- Open hardware RF designs with compatible licenses and clear stackup notes.

## What To Learn

- Antenna keepout strategy.
- RF connector placement.
- Feedline and ground stitching patterns.
- Matching network topology.
- Module placement constraints.

## What Not To Copy Blindly

- RF trace width without the same stackup.
- Matching component values without tuning evidence.
- Antenna keepout into a different enclosure.
- U.FL/SMA footprints without exact connector drawings.
