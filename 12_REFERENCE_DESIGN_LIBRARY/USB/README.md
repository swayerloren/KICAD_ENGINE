# USB Reference Designs

Use this folder for USB-C, micro USB, USB2 device, USB bridge, USB power, ESD protection, and USB connector reference design records.

## Preferred Sources

- USB controller or MCU vendor reference designs.
- Connector manufacturer drawings.
- Vendor hardware design guides.
- Open hardware USB boards with compatible licenses.

## What To Learn

- USB-C CC implementation patterns.
- D+ and D- routing and ESD placement.
- VBUS sense and power switching.
- Connector shield strategies.
- USB bridge support components.

## What Not To Copy Blindly

- USB-C connector footprints.
- CC resistor/current assumptions.
- Differential-pair geometry without stackup.
- Shield grounding strategy without enclosure/EMI review.
