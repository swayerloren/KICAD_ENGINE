# CAN Reference Designs

Use this folder for classical CAN, CAN FD, transceiver, termination, protection, and automotive/industrial CAN node reference design records.

## Preferred Sources

- CAN transceiver vendor reference designs.
- MCU vendor CAN/FDCAN examples.
- Automotive or industrial interface app notes.
- Open hardware CAN boards with compatible licenses.

## What To Learn

- MCU-to-transceiver wiring.
- VIO and logic-level handling.
- Termination and split termination examples.
- TVS and common-mode choke placement.
- Connector and harness conventions.

## What Not To Copy Blindly

- Termination into every node.
- CANH/CANL connector pinout.
- Automotive protection without target requirements.
- CAN FD assumptions from classical CAN-only designs.
