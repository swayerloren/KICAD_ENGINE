# Automotive Reference Designs

Use this folder for automotive power input, CAN/LIN, load switch, reverse polarity, transient protection, connector, and harness-oriented reference design records.

## Preferred Sources

- Automotive IC vendor reference designs.
- Transceiver vendor app notes.
- Protection device vendor app notes.
- Open hardware automotive projects with clear licenses and realistic safety notes.

## What To Learn

- Input protection chain patterns.
- TVS, fuse, reverse-polarity, and filtering approaches.
- CAN/LIN transceiver protection.
- Connector retention and pinout review practices.
- Ground/chassis strategy.

## What Not To Copy Blindly

- "12 V" assumptions without transient and fault requirements.
- Connector pinouts or harness conventions.
- TVS/fuse sizing without target environment.
- Designs with unclear safety, legal, or vehicle integration assumptions.
