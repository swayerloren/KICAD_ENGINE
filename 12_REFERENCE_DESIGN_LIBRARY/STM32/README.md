# STM32 Reference Designs

Use this folder for STM32 Nucleo, Discovery, evaluation board, and open hardware STM32 reference design records.

## Preferred Sources

- Official ST evaluation board schematics.
- Official Nucleo and Discovery board files.
- ST application notes and hardware getting-started documents.
- Open hardware STM32 boards with compatible licenses.

## What To Learn

- BOOT0 and reset patterns.
- SWD/ST-Link connector patterns.
- Crystal and clocking approaches.
- USB device implementations.
- CAN/FDCAN transceiver connections.
- VDDA/VSSA and decoupling practices.

## What Not To Copy Blindly

- Development board power architecture.
- ST-Link circuitry unless needed.
- Package pinouts across different STM32 families.
- Crystal values without checking the exact crystal and MCU.
- Header pinouts without target board requirements.
