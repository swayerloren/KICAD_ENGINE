# Power Reference Designs

Use this folder for regulator, charger, protection, eFuse, power tree, reverse polarity, TVS, and automotive input reference design records.

## Preferred Sources

- Regulator vendor reference designs.
- Evaluation board schematics and layout guides.
- Vendor application notes.
- Board-house or safety guidance where relevant.

## What To Learn

- Input protection sequencing.
- Buck regulator component placement.
- LDO capacitor requirements.
- Battery charger thermal and safety considerations.
- TVS, fuse, reverse-polarity, and ideal-diode patterns.
- Feedback routing and switching-loop control.

## What Not To Copy Blindly

- Inductor, diode, capacitor, or compensation values without exact design calculations.
- Layout from a different package.
- Thermal assumptions from a different board stackup.
- Automotive protection without explicit transient requirements.
