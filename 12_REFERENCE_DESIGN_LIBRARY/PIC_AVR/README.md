# PIC And AVR Reference Designs

Use this folder for Microchip PIC, dsPIC, PIC32, AVR ATmega/ATtiny, Curiosity, Explorer, Arduino-derived, and open hardware reference design records.

## Preferred Sources

- Official Microchip development board schematics.
- Microchip application notes.
- Official programming/debug tool documentation.
- Open hardware AVR/PIC boards with compatible licenses.

## What To Learn

- ICSP programming header patterns.
- MCLR/reset circuit patterns.
- Oscillator options.
- USB PIC and AVR USB circuit examples.
- 5 V versus 3.3 V design choices.
- Bootloader/programmer connector assumptions.

## What Not To Copy Blindly

- Arduino-style pin naming into bare MCU symbols.
- 5 V assumptions into 3.3 V systems.
- ICSP pin sharing without checking programming load constraints.
- Old forum or clone board layouts with unclear license.
