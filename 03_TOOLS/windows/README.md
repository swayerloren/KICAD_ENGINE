# Windows KiCad GUI Automation Tools

`03_TOOLS\windows` is for Windows desktop GUI control, visual automation, and native Windows inspection workflows.

Examples:

- pywinauto
- FlaUI
- FlaUInspect
- AutoHotkey
- PyAutoGUI
- SikuliX
- Inspect.exe notes
- Accessibility Insights notes
- Screenshot capture and comparison
- Window discovery scripts

Use Windows GUI automation carefully. Do not run it against real KiCad projects unless the active project, backup plan, verification plan, and rollback plan are confirmed.

No Windows GUI automation tools are installed by this structure step.
