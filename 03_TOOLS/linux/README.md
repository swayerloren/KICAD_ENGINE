# Linux KiCad Headless And GUI Automation Tools

`03_TOOLS\linux` is for Linux desktop automation, headless KiCad workflows, CI support, and container-oriented automation.

Examples:

- xdotool
- wmctrl
- ydotool
- dogtail
- Xvfb
- x11vnc
- PyAutoGUI on X11
- SikuliX Linux
- Docker
- Linux KiCad CLI
- KiCad AppImage control scripts

Use Linux automation outputs as review artifacts unless a project-specific verification gate explicitly approves manufacturing release.

No Linux automation tools are installed by this structure step.
