# KiCad Engine Project Gate Runner

Status: `READ_ONLY_EVIDENCE_AGGREGATOR`

## Purpose

This folder contains the one-command project gate runner for KiCad Engine. It
checks whether a KiCad project has the required evidence to pass the major
schematic, PCB, visual, footprint, DRC, unrouted-net, and fabrication-readiness
gates.

The runner is intentionally conservative:

- It does not edit KiCad files.
- It does not update PCB from schematic.
- It does not place, route, or refill zones.
- It does not generate Gerbers, drills, BOMs, pick-and-place files, or STEP.
- It does not run live ERC/DRC commands; it parses existing reports generated by
  the gated workflow.

## Command

From the repo root:

```powershell
.\03_TOOLS\scripts\project_gate\run_project_gate.ps1 -ProjectPath "19_TEST_PROJECTS\sample_kicad_projects\tomasr8_attiny85_dev_board"
```

Python equivalent:

```powershell
python .\03_TOOLS\scripts\project_gate\run_project_gate.py --project-path "19_TEST_PROJECTS\sample_kicad_projects\tomasr8_attiny85_dev_board"
```

Default output:

```text
05_OUTPUTS/gate_runs/<timestamp>/PROJECT_GATE_REPORT.md
05_OUTPUTS/gate_runs/<timestamp>/PROJECT_GATE_REPORT.json
```

## Gates

| Gate | Purpose |
| --- | --- |
| `SCHEMATIC_ANNOTATION_GATE` | Checks annotation evidence and falls back to a read-only schematic reference scan when the report is missing. |
| `ERC_GATE` | Parses existing ERC report evidence and fails on ERC errors. |
| `SCHEMATIC_VISUAL_GATE` | Requires full-page schematic export, close-up crops, and completed visual review. |
| `FOOTPRINT_AUDIT_GATE` | Requires footprint/package audit evidence and blocks unverified human-review items. |
| `PCB_SYNC_GATE` | Uses DRC/parity and PCB orientation evidence to determine sync status. |
| `DRC_GATE` | Parses existing DRC report evidence and fails on DRC/parity/unconnected-pad issues. |
| `PCB_VISUAL_GATE` | Requires PCB top/bottom visuals, close-up crops, and completed visual review. |
| `UNROUTED_NETS_GATE` | Parses DRC unconnected-pad summary. |
| `FAB_READINESS_GATE` | Blocks fabrication export unless final PCB verification explicitly permits `READY_FOR_NOT_FINAL_FAB_EXPORT`. |

## Final Classifications

- `PASS`: every required gate passes.
- `FAIL`: one or more gates failed or required evidence is incomplete.
- `PARTIAL`: no hard failures, but warnings or not-applicable gates remain.
- `BLOCKED_UNTIL_HUMAN_REVIEW`: one or more high-risk gates require human review.

## Missing Evidence Behavior

Missing upstream reports are reported as `INCOMPLETE` gate results. The runner
must not crash just because an ERC, DRC, visual, footprint, or fab-readiness
report is missing.

## ATtiny85 Golden-Path Fixture

The current promoted sample
`19_TEST_PROJECTS/sample_kicad_projects/tomasr8_attiny85_dev_board` is expected
to classify as `BLOCKED_UNTIL_HUMAN_REVIEW`. Existing reports show ERC, DRC,
footprint, connector-orientation, polarity, and human-review blockers. The gate
runner should surface those blockers honestly rather than claiming a clean pass.
