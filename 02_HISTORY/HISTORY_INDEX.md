# History Index

`02_HISTORY/` stores time-ordered evidence of what happened in the repo.

## Main Sections

- `sessions/`: human-readable session summaries
- `command_logs/`: executed command records
- `failed_attempts/`: things that did not work
- `issue_logs/`: unresolved blockers and risks
- `ai_self_reviews/`, `ai_scorecards/`, `claim_evidence_matrices/`, `uncertainty_logs/`: AI-quality closeout artifacts

## Use It For

- reconstructing prior work
- understanding why a report exists
- seeing what commands were run
- tracking unresolved repo-level problems

## Active Project Note

Project-local history also lives under each active project's `history/` folder.
