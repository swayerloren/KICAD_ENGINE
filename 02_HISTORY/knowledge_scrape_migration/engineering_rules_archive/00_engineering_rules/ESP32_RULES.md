# ESP32 Rules

- Start in `../05_esp32_espressif/` and prefer Espressif official docs first.
- Use original PDFs for module pinouts, antenna keepout drawings, package dimensions, and recommended layout figures.
- Treat `esp-idf`, hardware design guidelines, module datasheets, and TRMs as the primary stack.
- Cross-check USB, power, and RF decisions with `../07_usb_c_high_speed_esd/`, `../08_power_buck_regulators/`, and `../09_pcb_layout_grounding_emi_si/`.
- Use forums only after the Espressif source-of-truth set is exhausted.
- Cite local file paths and `url_index_id` for antenna orientation, keepout, boot strap pins, and power sequencing claims.
