# PCB Layout Rules

- Start with `../00_source_of_truth/SOURCE_OF_TRUTH_INDEX.md`.
- Use `../09_pcb_layout_grounding_emi_si/` for grounding, return path, EMI, SI, and decoupling guidance.
- Use `../10_dfm_fabrication_assembly/` and `../11_calculators_ipc_reference/` for board-house limits and calculator-based starting points.
- Cross-check high-risk layout claims with an official datasheet, app note, or fabricator rule before using forums.
- Treat calculators as starting points only, not final approval.
- Use original PDFs for package geometry, recommended layout, keepout diagrams, and thermal pad guidance.
- Cite local file paths plus `url_index_id` for connector placement, regulator loops, RF keepout, and fabrication constraints.
- Use `../12_forums_peer_review/` only for secondary review, not as primary authority.
