# Footprint Verification Rules

- Start in `../04_kicad_libraries_symbols_footprints/`.
- Use the exact manufacturer package drawing and land-pattern guidance before approving any footprint.
- Use original PDFs for pad geometry, tolerances, exposed pads, courtyard-sensitive dimensions, and orientation.
- Cross-check footprint guidance with KLC or the official KiCad library source when available.
- Treat extracted PDF Markdown as search text only for locating the exact page or drawing.
- Do not close a footprint decision from forums, videos, or generic CAD portals alone.
- Cite local file paths and `url_index_id` for package drawing, KLC, and library-source evidence.
