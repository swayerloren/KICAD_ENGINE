# Buck Converter Rules

- Start in `../08_power_buck_regulators/`.
- Prefer the regulator datasheet, official app note, and evaluation-board layout before blogs or forums.
- Use original PDFs for pin functions, compensation guidance, exposed-pad notes, and layout-current-loop diagrams.
- Treat extracted Markdown as search text only when locating the original document.
- Use `../09_pcb_layout_grounding_emi_si/` for return-path, EMI, and decoupling cross-checks.
- Use `../11_calculators_ipc_reference/` only for quick starting values, not final power-stage approval.
- Cite local file paths and `url_index_id` for switch-node, bootstrap, input-cap, and inductor-loop recommendations.
