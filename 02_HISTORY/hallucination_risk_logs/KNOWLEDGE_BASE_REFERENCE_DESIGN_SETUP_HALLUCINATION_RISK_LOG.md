# Hallucination Risk Log - Knowledge Base Reference Design Setup

Date: 2026-05-02

Risk label: `LOW_RISK`

## Risk

Future agents could misuse reusable circuit guidance or link-only reference entries as if they were verified datasheet evidence.

## Mitigation Added

- Knowledge-base index states that patterns are not approval.
- Reference-design schema uses conservative statuses.
- Starter reference entries are marked `LINK_ONLY`.
- README handoff files warn future agents that reference designs are evidence only.

## Human Review Required

Required before applying any reference-design lesson to an active schematic, PCB layout, footprint, connector orientation, or manufacturing package.
