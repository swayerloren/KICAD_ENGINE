# AI PCB Routing Failure Patterns

Status: `EVIDENCE_SUMMARY`

## Repeated Failure Types

- right-angle corner acceptance
- acute bend acceptance
- long rectangular perimeter detours
- routing before placement or mechanical truth is proven
- open-net regressions hidden behind a clean geometry summary
- test pads attached as long route destinations instead of short leaf stubs

## Use

Use this file as historical evidence for why the PCB quality gate rejects those
patterns.
