# Schematic Readability Failure Patterns

Status: `EVIDENCE_SUMMARY`

## Repeated Failure Types

- label-only local wiring inside a functional block
- scattered blocks with no clear left-to-right or top-to-bottom flow
- references and values overlapping wires, pins, or symbols
- visible `NEEDS_REVIEW` values left in the main drawing
- annotation assumed complete from text scans alone

## Use

Use this file as historical evidence for why readability and native annotation
remain separate gates from ERC.
