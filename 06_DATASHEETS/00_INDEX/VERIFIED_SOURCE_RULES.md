# Verified Source Rules

Use these rules before relying on a datasheet for symbol, footprint, BOM, power, or fabrication decisions.

## Preferred Sources

1. Manufacturer official product page.
2. Manufacturer official document portal.
3. Manufacturer official GitHub or design repository when clearly linked by the vendor.
4. Authorized distributor page that links to the manufacturer document.
5. Board-house official fabrication or assembly capability page.

## Required Metadata

Record the following for every curated document:

- Source URL.
- Access date.
- Vendor or publisher.
- Part number or topic.
- Document type.
- Revision, publication date, or document number when available.
- Local file path when a local copy is stored.
- Copyright or redistribution note when known.

## Agent Restrictions

- Do not download documents unless the user asks for that task.
- Do not treat third-party mirror sites as authoritative without a better source search.
- Do not infer footprint correctness from a filename alone.
- Do not use stale or unversioned documents without noting the risk.
