# Source Priority Rules

Date: 2026-05-02

Status: authoritative-source ranking for datasheet research.

## Preferred Source Order

1. Official manufacturer product page for the exact part number.
2. Official manufacturer documentation portal.
3. Official manufacturer reference design, hardware design guide, errata, or app note.
4. Official manufacturer GitHub or design repository clearly linked from the vendor.
5. Authorized distributor product page that links back to manufacturer documentation.
6. Board-house official fabrication or assembly reference page.
7. Community notes only as leads, never as authoritative source.

## Avoid As Primary Sources

- Random PDF mirrors.
- Search-engine PDF cache links.
- Forum uploads.
- Distributor-hosted documents without manufacturer linkage.
- AI-generated summaries without source citations.
- Old local files with no source URL or revision.

## Exactness Rule

For design use, source evidence must match:

- Exact vendor.
- Exact part number.
- Exact package.
- Exact document type.
- Exact revision/date when available.
- Exact use case where reference designs are involved.

## URL Strategy

- Prefer product pages and documentation portals over direct PDFs for initial source lists.
- Add direct PDF URLs only after verifying they are official, current, and allowed by policy.
- Keep one row per document type when the exact source is known.
