# Copyright And Linking Policy

This library must stay useful without ignoring datasheet copyright and redistribution rules.

## Local Copies

Local copies are acceptable only when the user intentionally stores them for private engineering reference or the document license permits redistribution. When in doubt, store a source URL and metadata instead of adding a PDF.

## Public Release Risk

Before publishing this repo publicly:

- Review every stored PDF and reference document.
- Remove documents that cannot be redistributed.
- Keep vendor URLs and metadata in indexes.
- Prefer links, document numbers, and source notes for public-facing records.

## Agent Rules

- Do not download datasheets without explicit approval.
- Do not bulk mirror vendor document portals.
- Do not claim redistribution permission unless the license or vendor policy is checked.
- Keep copyright uncertainty visible in `SOURCES.md`.
