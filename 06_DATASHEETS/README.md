# 06_DATASHEETS

## PURPOSE
AI-friendly datasheet and reference-document metadata library.

## WHAT_BELONGS_HERE
- Source links.
- Datasheet metadata.
- Summaries.
- Missing-document trackers.
- Redistribution policies.

## WHAT_DOES_NOT_BELONG_HERE
- Restricted PDFs without redistribution review.
- KiCad project source files.
- Secrets.

## AI_AGENT_RULES
- Do not invent datasheet values.
- Prefer official vendor sources and link-only public records unless redistribution is confirmed.

## SAFE_EDIT_RULES
- Do not mass-download documents.
- Mark missing or uncertain documents clearly.

## PUBLIC_RELEASE_NOTES
- Public releases should avoid bundled copyrighted PDFs unless redistribution rights are confirmed.
