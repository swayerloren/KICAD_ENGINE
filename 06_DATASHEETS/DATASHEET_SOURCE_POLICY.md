# Datasheet Source Policy

## Priority Order

1. Official manufacturer datasheet
2. Official manufacturer application note
3. Official module/mechanical drawing
4. Official package information portal
5. Approved local mirror with source-provenance record

## Allowed Canonical Content

- source links
- source-registry IDs
- safe summaries
- missing-document notes
- redistribution status

## Not Allowed As Proof By Themselves

- vendor listing pages
- distributor filters
- part-search result pages
- forum reposts
- OCR-only or extracted markdown without source link

## Migration Rule

If a migrated intake file is a copied page, PDF, or extracted PDF
markdown and redistribution rights are unclear, the canonical system stores the
source link here and the raw file in license quarantine.
