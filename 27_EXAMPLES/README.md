# Examples

Status: `EXAMPLE_ONLY`

## PURPOSE

Store public-safe examples that demonstrate KiCad Engine workflows without exposing private work or implying fabrication approval.

## WHAT_BELONGS_HERE

- Example prompts.
- Example reports.
- Example metadata records.
- Safe sample workflow walkthroughs.
- Memory/history examples.
- Component record examples.
- Datasheet summary examples.
- Quality scorecard examples.

## WHAT_DOES_NOT_BELONG_HERE

- User-private projects.
- Final fab outputs.
- Copyrighted datasheets without redistribution review.
- Secrets or credentials.
- Unsupported benchmark results.

## AI_AGENT_RULES

- Mark examples clearly as examples.
- Do not treat examples as verified engineering defaults.
- Keep manufacturing outputs `NOT_FINAL`.
- Every file in this folder must be marked `EXAMPLE_ONLY` unless it is a folder README explaining example policy.

## SAFE_EDIT_RULES

- Add example docs and safe metadata.
- Do not copy active project files here without explicit approval and public-safety review.

## PUBLIC_RELEASE_NOTES

Examples must be safe for GitHub release and should include source/verification status.
