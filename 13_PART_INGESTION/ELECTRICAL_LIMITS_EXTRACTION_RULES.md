# Electrical Limits Extraction Rules

## Extract Only With Source Evidence

Do not invent:

- Voltage ranges.
- Current limits.
- Absolute maximum ratings.
- Recommended operating conditions.
- Thermal resistance.
- Logic thresholds.
- ESD ratings.
- Power dissipation.

## Required Separation

Keep these separate:

- Absolute maximum ratings.
- Recommended operating conditions.
- Typical performance values.
- Test conditions.
- Application circuit examples.

## Warning

Absolute maximum ratings are not design targets.

## Output

Each extracted value should include:

- Field name.
- Value.
- Source document.
- Page, section, table, or figure when reviewed.
- Notes and assumptions.

If not reviewed, use `Unknown - requires source verification`.
