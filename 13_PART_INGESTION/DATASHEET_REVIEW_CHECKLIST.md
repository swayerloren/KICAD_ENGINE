# Datasheet Review Checklist

Use this checklist before turning a datasheet into design data.

## Source And Rights

- Source URL recorded.
- Local path recorded if user provided a file.
- Redistribution status recorded.
- Public release should remain link-only unless redistribution is confirmed.
- Document title, revision, and date recorded if available.

## Identification

- Exact part number.
- Vendor.
- Family.
- Package/module variant.
- Lifecycle status.
- Variants covered by the document.

## Electrical

- Recommended operating conditions.
- Absolute maximum ratings.
- Supply voltage range.
- Supply current and output current limits.
- Power and thermal limits.
- Logic voltage domains.

## Pinout And Package

- Pin count.
- Pin table.
- Pin 1 orientation.
- Package drawing.
- Land pattern.
- Exposed pad requirements.
- No-connect pins.

## Design Guidance

- Required external parts.
- Decoupling.
- Reset/enable/boot pins.
- Clocking.
- Interface-specific notes.
- Layout notes.
- Thermal notes.
- RF/high-speed notes.
- Connector orientation notes.

## Risk

- Known errata.
- Common mistakes.
- Unclear values.
- Human review required.
