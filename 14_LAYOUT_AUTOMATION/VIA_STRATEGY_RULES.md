# Via Strategy Rules

## Purpose

Define when vias are acceptable and how they should be reviewed.

## Rules

- Avoid unnecessary vias.
- Every via on a critical net should have a routing reason.
- Prefer layer-stable routing where possible.
- Do not use vias as a substitute for bad placement.
- Via count is part of routing-quality scoring.

## Required Audit Fields

- via count per net
- via reason when vias exist on critical nets
- whether the via seems required or optional
