# Test Pad Placement Rules

## Purpose

Define placement rules for test pads and debug access.

## Rules

- Test pads must remain accessible after assembly.
- Prefer rows or columns with consistent spacing.
- Do not bury test pads behind connector shells, cable paths, or tall parts.
- Keep related test pads grouped but separate from dense high-priority clusters.

## Failure Conditions

- inaccessible test pads
- test pads mixed into USB, RF, or power clusters
- test pads placed inside connector keepouts or mounting-hole clearance zones
