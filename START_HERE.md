# Start Here

This is the shortest public entry point for humans using KiCad Engine.

KiCad Engine is a general AI-assisted KiCad workflow repo, not just one board project.

## Fast Path

1. Download the GitHub ZIP or clone the repo.
2. Open the `KICAD_ENGINE` folder in VS Code.
3. Read [README.md](README.md).
4. Read [ONE_PROMPT_START.md](ONE_PROMPT_START.md) if present.
5. Read [CURRENT_STATUS.md](CURRENT_STATUS.md), [PROJECTS_INDEX.md](PROJECTS_INDEX.md), [WORKFLOWS_INDEX.md](WORKFLOWS_INDEX.md), and [TOOLS_INDEX.md](TOOLS_INDEX.md).
6. If you want the full agent startup stack, read [00_CODEX_START/START_HERE.md](00_CODEX_START/START_HERE.md).

## What This Repo Is For

- using Codex or Claude inside VS Code with local KiCad projects
- creating or reviewing projects under `04_KICAD_PROJECTS/active`
- keeping older or reference projects under `04_KICAD_PROJECTS/archive`
- starting new work from `04_KICAD_PROJECTS/templates`
- using repo rules, scripts, checklists, and validation workflows around KiCad work

## Important

- `ESP32_CSI_WIFI_NODE` is only the current example/current active project
- it is not the identity of the whole repo
- no extra GitHub repos are required for the basic local workflow
- human review in KiCad is still required before fabrication
