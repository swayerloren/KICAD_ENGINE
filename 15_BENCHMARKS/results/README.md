# Benchmark Results

Status: empty by design.

Do not add benchmark scores here unless a benchmark was actually run using the documented methodology.

## Required Result Package

Each real result folder should include:

- `BENCHMARK_RESULT.md`
- `benchmark_result.json`
- `artifact_manifest.json`
- `score_breakdown.md`
- `human_review_required.md`
- `unknowns_and_unverified_claims.md`
- Source/citation manifest or equivalent links.
- ERC/DRC/BOM/output artifacts when required by task scope.

## Naming Convention

Use:

`YYYYMMDD_TASK_###_TOOL_OR_AGENT_NAME`

Example:

`20260503_TASK_001_CODEX_LOCAL_RUN`

Do not create example result folders unless they are clearly marked as documentation-only and contain no scores.

## Publication Gate

A result is not public comparison material until it has:

- Complete run metadata.
- Preserved or summarized artifacts.
- Reviewer notes.
- Human review flags.
- No fake source claims.
- No fabrication-ready wording.
