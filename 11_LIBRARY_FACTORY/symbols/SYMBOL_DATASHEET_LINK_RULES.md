# Symbol Datasheet Link Rules

## Required Link Behavior

The symbol datasheet/source field should point to:

- The exact vendor datasheet.
- A local summary record that cites the exact vendor datasheet.
- A vendor product page when the direct datasheet URL is unstable.

## Public Repo Policy

- Prefer source links and metadata for public release.
- Do not bundle copyrighted datasheets unless redistribution is confirmed.
- Do not fabricate source URLs.

## Link Metadata

Record when available:

- Source title.
- Vendor.
- Revision/date.
- URL.
- Access date if useful.
- Relevant page/table/section for pinout.

## Review Gate

If the datasheet/source field is missing or generic, the symbol remains `UNVERIFIED_SYMBOL`.
