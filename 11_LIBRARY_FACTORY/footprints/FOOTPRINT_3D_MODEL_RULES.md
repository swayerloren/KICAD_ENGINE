# Footprint 3D Model Rules

## Purpose

3D models support mechanical review but do not prove land-pattern correctness.

## Rules

- Use 3D models that match the exact part when available.
- Verify scale, rotation, offset, and side.
- Do not accept a footprint because the 3D model looks close.
- Missing 3D model should be recorded, not hidden.
- Connector 3D models require extra orientation review.

## Review Uses

3D models help check:

- Connector direction.
- Mechanical clearance.
- Component height.
- Enclosure fit.
- Cable exit direction.

## Review Gate

3D model status is separate from footprint verification status.
