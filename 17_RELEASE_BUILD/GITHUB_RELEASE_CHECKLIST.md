# GitHub Release Checklist

Status: `DRAFT_RELEASE_ONLY`

## Required Before Draft Release

- Health check passes.
- Payload build passes.
- Secret scan completes.
- License audit updated.
- Datasheet redistribution audit updated.
- Public docs reviewed.
- Installer artifacts built on platform runners.
- SHA256 checksums generated.
- Release notes include limitations.
- No release auto-published.

## Required Human Review

- License and attribution.
- Security notes.
- Installer signing/notarization status.
- Known blockers.
- README claims.
- Any comparison to cloud PCB AI tools.
