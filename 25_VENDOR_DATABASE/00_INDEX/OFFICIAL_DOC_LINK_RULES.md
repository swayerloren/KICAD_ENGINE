# Official Document Link Rules

Status: `ACTIVE_RULES`

## Link-First Default

For public repo use, store official links, metadata, and summaries by default.

## Required Metadata

- Vendor.
- Document title.
- Document type.
- Source URL.
- Revision/date if known.
- Redistribution status.
- Local copy status.
- Notes.

## Do Not

- Do not invent direct PDF URLs.
- Do not bypass vendor restrictions.
- Do not redistribute documents without permission.
- Do not treat a stale link as a verified current document.
