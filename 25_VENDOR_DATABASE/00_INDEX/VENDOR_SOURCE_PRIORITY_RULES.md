# Vendor Source Priority Rules

Status: `ACTIVE_RULES`

## Source Priority

1. Official vendor product page.
2. Official datasheet or reference manual.
3. Official errata.
4. Official application note.
5. Official evaluation board schematic or reference design.
6. Authorized distributor product page.
7. Reputable open hardware project with compatible license.
8. Community/forum content only as a lead, never as final evidence.

## Rules

- Prefer official vendor sources.
- Record source URL and access/review date.
- Mark time-sensitive sourcing and lifecycle information clearly.
- Do not scrape aggressively.
- Do not store account credentials.
