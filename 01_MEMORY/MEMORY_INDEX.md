# Memory Index

`01_MEMORY/` stores durable reusable knowledge that should survive across sessions and projects.

## Typical Contents

- global process memory
- design rules
- known mistakes and lessons learned
- component or fab-house preferences
- reusable workflow knowledge

## Use It For

- stable decisions
- reusable lessons
- rules worth reapplying

## Do Not Use It For

- transient command output
- one-off logs
- secrets or credentials

Project-specific durable memory belongs in each active project's `memory/` folder.
